# 角色聊天

正式网站：<https://juese.onrender.com>

浅粉色的手机、平板与电脑聊天页面，6位女性、6位男性，各有写真人像、性格、开场、兴趣和8个可聊话题。头像均为虚构成年人物，随站点发布。

## 角色与聊天

女性：暖暖（温柔甜美）、林晚（成熟性感）、苏棠（甜美俏皮）、许知夏（开放洒脱）、叶清歌（狂野热情）、零一（叛逆慢热）。男性：陆沉（沉稳可靠）、小太阳（开朗暖心）、沈砚（安静体贴）、顾言（温柔知性）、江屿（阳光坦诚）、云舟（温雅从容）。

点击聊天顶部的人像查看人设。角色消息左侧、玩家消息右侧都有头像；自己的头像和自建角色头像都可从相册选择，在浏览器内裁剪、压缩为384像素，不需要填写网址。

可发6000字，选择随聊随回、短一点或认真长聊，并使用表情面板。回复来自真实模型，没有本地随机假回复。底部不显示“正在回复”中文案；真实内容一到就显示，完成后写入历史。手机键盘弹出时，聊天区与角色弹窗跟随可见区域的高度和上边缘，保留内部滚动。

768像素及以上并排显示角色列表和聊天区，角色列表单独滚动，管理入口保持可见。平板分屏或窄窗口使用抽屉；平板触屏键盘弹出时也使用抽屉，为聊天保留宽度。横竖屏切换自动清理遮罩。宽屏创建角色和资料记忆使用双列，创建按钮固定在表单底部；记忆备份、恢复记忆保持等宽等高。电脑可用Enter发送、Shift+Enter换行，中文输入法确认不触发发送；Tab在当前弹窗内切换，Escape关闭并恢复焦点。

## 单独上传新角色代码

固定入口：**角色中心 → 上传角色代码**。弹窗中可点**上传文件**，也可直接**编写或粘贴角色代码 → 生成角色**。**使用模板**会填入可编辑的完整配置和新的角色id；关闭弹窗或刷新后，在同一浏览器标签页内保留尚未提交的草稿。电脑支持Ctrl/Cmd+Enter生成。单独模板仍为 **roles/new-role.role.json**，网页可下载。填写name和personality，自动接入头像、开场、话题、真实聊天和记忆；无需修改网页或聊天程序。

一次可添加1到24个角色；同一id重复导入会跳过，不覆盖原记忆。使用标准JSON，也支持.js文件中的export default或module.exports =后接标准JSON。上传程序不会执行。完整字段与批量配置见roles/README.md和roles/preset-roles.json；预设人设的唯一维护入口仍为roles.js。

模板、12位预设配置和添加说明已保存到[Google Drive角色配置文件夹](https://drive.google.com/drive/folders/1JRbjHp0rLKTZzsrZSHw9ULqBdjFtif7A)。

## 长期记忆和备份

每台设备有稳定的玩家id、称呼和个人资料；每个角色记录明确自述、表达偏好和上次聊天日期。最近20条用于上下文，相关长期记忆单独带入。姓名、宠物和重要偏好不会仅因为闲聊超过20条就丢失，久别回来可以按真实间隔自然接续。

明确的语气反馈会保存，之后按最新偏好慢慢调整，同时保留各自性格；这是记忆和提示词调整，不是训练模型权重。角色中心的“资料与记忆”可编辑资料、添加相处偏好、查看或忘掉细节。老版本记录会保留，并迁移明确自述。清空对话保留长期记忆；删除自建角色也删除其聊天与记忆。

旧保存键liaotian_custom_chars、liaotian_chat_histories、liaotian_active_char继续使用，新增liaotian_user_avatar、liaotian_player_profile、liaotian_role_memories、liaotian_reply_length。照片不提交给聊天接口；当前人设、相关记忆和最近对话用于模型回复。

备份包括头像、玩家资料、自建角色、聊天和记忆。“记忆备份”在支持文件分享的手机上可选择Google Drive，否则下载JSON后上传自己的Drive。“恢复记忆”可在新手机接续。**日常记忆当前保存在浏览器，尚未连接Google自动云端同步**。清除浏览器数据或换手机前请保存备份；分享菜单和下载不会谎报为Google云端保存成功。

## 回复冗余

现有role-chat-fast接口源码在supabase/functions/role-chat-fast/index.ts。网站的4条真实模型通道竞速首批有效内容，先到者显示，其余取消；失败或空回复不会成为赢家。兼容未流式输出的上游JSON。网页预热连接只发OPTIONS，不生成回复或发送玩家资料。

短回复180 token、普通300、长文1200，后台上限1400；旧入口保留180 token及原5通道。仅网站启用流式与末条用户消息6000字。首批内容超时9秒、完整回复32秒，前端总等待最多40秒。无内容的临时故障自动再试一次，断网保存消息、联网自动继续。部分内容传输中断会明确提示，不当作完整回复保存。免费通道与网络不能保证每次秒回或永不失败。

角色请求独立，切换时回复留在原角色；清空或删除会取消，迟到结果不写回。重试不重复插入玩家消息，失败不伪造回复。本机JSON损坏有读取回退，空间不足会提示备份。
