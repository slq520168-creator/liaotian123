# 角色聊天

正式网站：<https://juese.onrender.com>

手机和桌面共用一个页面，可切换预设角色、创建自己的角色、保存各角色的独立聊天记录。

## 角色与回复

- 唯一的预设人设入口是 roles.js，共 12 个角色，6 女、6 男。女性：暖暖（温柔细腻）、林晚（成熟知心）、苏棠（俏皮活泼）、许知夏（知性独立）、叶清歌（温雅文艺）、零一（理性细心）。男性：陆沉（沉稳可靠）、小太阳（开朗暖心）、沈砚（安静体贴）、顾言（温柔知性）、江屿（阳光坦诚）、云舟（温雅从容）。
- 每个角色都有自己的年龄、性格、口吻、兴趣、开场、头像和快捷话题。
- 全站采用浅粉色背景。预设头像使用12张独立的AI生成写真人像，6女6男；头像文件随站点发布，无需外部图片服务。
- 角色左侧、用户右侧的每条聊天消息都有头像。输入框旁的“头像”和已发消息旁的头像都能打开手机相册，设置自己的头像。
- 自建角色可以选择预设人像或从相册选择照片，自动居中裁剪、压缩为384像素头像；支持浏览器可读取的照片格式。无法读取时明确提示，不显示虚假的上传成功。
- 每位预设增加背景、相处方式及日常/开心/委屈/安静/建议/故事6种情境指导，并提供8个可聊话题。自建角色可分别填写说话习惯、爱好和相处方式，回复仍由真实模型生成。
- app.js 调用既有 role-chat-fast 接口，提交当前角色的人设和最近 20 条对话。每条消息最多 1600 字，与接口接收范围一致。自定义角色也使用同一真实模型接口，没有随机关键词回复。
- 本网站带 client: liaotian123 和 max_tokens: 480 请求更完整的回复，后台最多允许640 token；其他入口保留180 token默认值。网站使用4条支持完整上下文与长度参数的真实模型线路；旧入口保留原线路。正式函数源码位于 supabase/functions/role-chat-fast/index.ts。
- 请求等待、失败和重试均对应真实网络状态。失败不会写入伪造的角色消息，重试不会重复添加用户消息。
- 每个角色最多一个正在进行的回复。切换后回复保存在原角色，清空或删除时取消请求，迟到结果不会污染对话。

## 代码添加新角色

只在 roles.js 的 NEW_ROLE_CONFIGS 预留区添加配置。名字、人设和唯一 id 必填，其余字段使用默认值，也可以自行填写。列表、男女角色人数、头像选择、开场和真实模型回复自动接入，无需修改其他文件。

```js
const NEW_ROLE_CONFIGS = [
  {
    id: 'unique_role_id',
    name: '角色姓名',
    gender: 'male',
    age: 28,
    personality: '写明性格、说话习惯和相处方式。',
    avatar: 'assets/avatars/luchen.svg',
    greeting: '今天想聊什么？'
  }
];
```

## 本机保存

角色和记录使用原有 liaotian_custom_chars、liaotian_chat_histories、liaotian_active_char 键保存；自己的头像保存到 liaotian_user_avatar。相册头像只在当前浏览器处理和保存，不上传到本站或聊天接口。当前角色的人设及最近对话会提交给现有聊天接口生成回复。清理浏览器数据或换设备后，本机记录和头像不会自动恢复。

config/role.json 保留旧版暖暖设定供参考，当前页面以 roles.js 为准。

## 检查与部署

    node --check roles.js
    node --check app.js

PR 和推送会运行语法检查，便于在合并前发现坏脚本。render.yaml 中的构建命令也执行同一检查。Render 静态发布路径为 ./，main 合并后自动部署；无需手动重复触发。

上线验收：手机宽度、角色切换、创建角色、刷新保存、真实多轮回复、错误重试、等待时切换、清空和删除时取消请求。
