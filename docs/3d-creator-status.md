# 3D 创建流程与验收状态

2026-10-29：按参考图的信息结构调整为基础身份、外貌、脸 / 发型、身体、个性、完成六步。复用既有 WebGL 舞台和 GLB，不使用参考网站品牌或人物图片。

## 已实现的代码路径

- 新创建器使用 creatorVersion=2 的可编辑 recipe；旧固定底座角色兼容保留。新配方保存身高、体重、肤色、眼色、发色、脸部及身体参数，编辑和恢复时不再归零。
- 六种肤色、扩展发色与眼色独立更新材质。颜色变化不重新加载 GLB；虹膜颜色纳入渲染缓存键。
- 既有八种发型加载真实网格。切换时保留当前人物，替换模块准备好后提交；过期下载释放。
- 脸部起点与细调、体型、胸部、身高和体重映射既有真实 morph。人物类型是可调艺术预设，不是族群生理标准，不锁肤色。
- 固定高度的手机底部参数面板、桌面右侧参数面板、六步导航、保存前外观与个性摘要、保存后详情跳转编辑。
- 职业、关系、爱好、问候语、性格与场景文字进入现有角色资料。害羞与开朗同时影响回复提示、视线、头部与表情动作。
- 数据仍按现有架构保存于当前浏览器及 IndexedDB；没有新增云同步服务。

## 第二批实现（create3d51）

- 运行时生成 12 个真实正负 Morph Target，覆盖腰围、髋宽、臀部体积、肩宽、腿部体积与腿长；对身体、服装与头发应用同一位移场，并扩展关节偏移。肌肉及丰满微调复用原生目标。身体更改在 160ms 内插值，取消时保留已显示的形状。
- 臀部预设、13 项身体微调、运动型预设、自定义关系及助手关系；所有数值保存到 recipe。
- 精灵耳、角、光环、触角为真实网格，跟随头骨；人物类型选择会应用对应配件，肤色仍独立。
- 虹膜 shader 使用左右眼独立颜色 uniform 与发光量；颜色 / 发光修改不重载人体网格。新增渲染缓存签名避免右眼参数被忽略。
- 波浪卷对长发实际顶点及 morph 位移作卷曲变换；刘海与双丸子使用基础程序网格，绑定相同头骨与 morph 字典；自定义长发支持卷曲程度。它们是基础造型，需要视觉验收，不能宣称达到参考照片的写实发丝质量。
- 固定工作室包含地板、墙、窗、沙发、边桌和植物网格，复用现有灯光，少于 40 个 mesh、3000 个三角形。文字场景字段只控制对话情境。
- 保存后进入角色主页，同一实时舞台保留，外观 / 个性条目点击返回对应步骤；主页与聊天状态可切换。上下拖动平移相机，双指缩放与重置保留。
- 沉浸式聊天与主页采用深色半透明界面。

## 尚未完成，不能视为完整交付

- 工作室可显示真实几何，但场景漫游和家具交互未实现；第一阶段只提供固定场景。

## 验证范围

自动测试覆盖新版配方序列化恢复、现有 GLB morph 名称、独立颜色材质更新、人格动作差异、过期模块加载清理；使用真实 GLTFLoader/Meshopt 解码生产 GLB，检查新增形变顶点、服装、头发、关节数据和可逆性。另测试眼睛 shader 注入与 uniform 切换、场景网格预算及资源释放、相机纵向查看、发型骨骼与目标合同。保留原有模型、聊天、存储、资产校验。

本次云浏览器无法启用 WebGL2。界面可操作，但不能在该环境验证实际人物外观、保存后的完整 3D 闭环或音画同步。不得将此测试记录作为移动端合格证。

语音阻塞：当前仓库使用系统 speechSynthesis，未配置能返回音频与真实音素时间戳的 TTS 服务。精确嘴型同步需要这项服务；不能用定时张嘴或文字边界伪装。
