# Liaotian123 角色扮演正式化：2D 动态模型生产规范

## 已保留的正式业务链路

角色名单、人设、关系、开场白、对话历史、长期记忆与备份继续使用现有 roles.js、app.js、memory.js。原有 12 个预设角色的 ID 不更改；旧 3D 创建功能仍独立保留。

普通 2D 自建角色使用原角色数据结构与 localStorage，不再被旧的“只允许 3D”启动清理过滤。新数据修复是非破坏性合并；禁止删除任何用户历史记录。

## 人物资产现状与技术

正式仓库的 12 个角色照片均只有 256×256 JPEG，可用于头像和静态回退；这些照片不属于真实 Live2D／Mesh Avatar 模型。2026-11-23 这轮没有新制作的可验收人物模型文件，不能把播放器已集成称为 12 个角色已经会动。

本项目集成 MIT 开源 Mesh Avatar Studio 的自托管 mesh-avatar-element 0.4.5，浏览器只在确有模型时加载。网页安全策略不放行第三方 JavaScript；禁止加载第三方样例 Miko 充当原角色。

## 一名角色从原画到正式上线的流水线

1. 从现有角色 ID 出发，绘制相符的高分辨率正面半身原画，拥有明确的商业使用权。角色卡、聊天动态人物与人物视频必须保持同一外观。
2. 在 https://github.com/shinshin86/mesh-avatar-studio 按官方 Agent Guide 制作 rig 和分层：人物头脸、眼睛、嘴巴、头发，尽可能有闭眼、半闭眼与元音嘴型差分。
3. 使用官方工作室进行眼睛关闭、头部转动、说话嘴型和头发物理测试。检查 ±30° 角度、iPhone Safari 性能和资源释放。失败即继续调整资源，不以简单头像上下漂浮替代。
4. 把验证过的角色导出成 .mavatar，放入 assets/role-models/<角色ID>.mavatar。模型应小于 30 MB，不与其他角色共享人物身份。
5. 在 assets/role-models/manifest.json 的 models 中加入同名角色条目，包含 src、license（OWNED、CC0 或 CC-BY-4.0）以及 author。运行 node scripts/validate-role-models.mjs 验证资源路径、许可、大小和文件格式。
6. 模型发布后只为对应角色启用真实 2D 模型，加载失败自动回退原角色照片，不影响 AI 回复、原人设和历史记录。

## 语音与口型的真实界限

当前浏览器 speechSynthesis 会报告开始／结束；支持的浏览器还能报告词边界。我们只在真实 TTS 的词边界给予近似口型提示，不把它冒充音频分析的精准对口型。未来接入音频时间轴或 WebAudio Analyser 才能对齐逐音素嘴型。

## 正式验收

- 第一阶段：女性＋男性各 1 名具有完整 2D 模型和表达动作，实际 iPhone Safari 测试通过，再扩展其余 10 名；不把尚无模型的角色标为完成。
- 第二阶段：12 个原人设、历史与角色记忆不丢，创建／编辑 2D 自建角色、上传头像、切换、返回大厅、回复与出错重试均正常。
- 第三阶段：桌面、安卓、iPhone Safari/PWA 持续测试，检查 GPU 内存、文本气泡、键盘弹出、切后台恢复以及语音中止后的状态。
- 部署成功不等于实机验收成功；任何未完成项必须明确列出。

## 回退与不变更项

不碰 IM，不修改 Supabase 表和其他站点。运行时使用角色级模型配置，可通过不发布对应模型条目安全回退成原照片；数据源不回退、不删除本地聊天记录。
