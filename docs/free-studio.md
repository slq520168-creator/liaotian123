# 原创角色创作工作台

入口为 [工作台](../studio/index.html)。首页进入新工作台，原有 3D 角色聊天与创作器保留在 [原有入口](../index.html?legacy=1)。不删除、迁移或裁剪旧角色数据。

## 实际实现

- 读取 `roles.js` 的十二位原创成年角色，初次使用时复制本机自定义角色；此后工作台独立保存角色、性格、背景、外观、关系、显式记忆、开场白和声音设置。
- 角色聊天通过新增 `liaotian-studio-free` 后台函数转发至 Pollinations Classic 的 OpenAI 兼容免费接口，仅接受实际非空模型回复。输入、失败重试和各角色对话独立保存。不会把本机开场白当成接口返回。浏览器不直连接口，避免经典服务的浏览器验证限制。
- 人物大图使用经典免费文生图，开启 `safe=true`，尺寸请求为 512×768。中文描述先通过同一免费文字接口翻译为英文，因此也占用文字接口额度；如果刚聊天，可能需要先等待文字额度冷却。免费服务可能调整实际输出尺寸，带服务商标记；不承诺与头像一致的人脸。安全检查拒绝的描述不绕过过滤。
- 头像由真实大图本机裁切为 256×256，支持上下调整；用户也能上传普通图片，再裁切头像。原有3D页面新增「保存3D人物图」，直接把当前实际场景以768×1024离屏渲染到工作台作品库，不依赖任何模型接口，可保持人物外观一致。需要原3D角色成功加载，不能用未加载的场景伪造导出。默认大图区域明确标记为旧头像预览，不能当作生成的高清图。
- 语音输出用系统 `speechSynthesis`，可选设备音色和六种节奏／音高风格，不克隆真人声音。自动朗读默认关闭。系统可用音色依设备和联网状态而变。
- 语音输入用浏览器 `SpeechRecognition`，先转成文字，由用户检查后发送。需要浏览器支持、麦克风权限，可能交给浏览器厂商处理。失败可继续打字。
- 过场使用本机 Canvas 镜头推进、淡入淡出与字幕，最多三个分镜、4/8/12 秒。支持的浏览器用 `MediaRecorder` 录制并下载真正的 WebM 文件；不是 AI 视频，无音轨，不假称有嘴型同步。
- 角色和聊天用专用 localStorage 保存，实际大图、头像和视频用专用 IndexedDB 保存。完整 JSON 备份包含作品数据，可合并恢复；不默认云同步。

## 免费边界

2026-11-17 检查官方 [经典接口文档](https://github.com/pollinations/pollinations/blob/master/APIDOCS.md)，并实测文本与图片接口均返回 HTTP 200。这只证明当次可用，不是持续服务保证。

官方目前标明经典接口无需密钥，每 IP 的图像和文字各自至少间隔45秒。返回402或429时等待，不进行 x402 付款、不购买额度、不转到收费服务。限额与模型可能改变，没有可用性保证；这不是无限免费服务。

文字请求会把用户文字、人设和上下文经本站已有 Supabase 免费计划后台发给 Pollinations。文生图把外观和场景写入经典图片提示词链接，结果可能被公共缓存；不要填写身份、密码、真实住址等敏感资料。首次调用前需确认服务说明。后台保留 JWT 校验、来源白名单、输入限制及每IP每类45秒的尽力限流；多实例仍受上游共享IP额度限制，不是分布式限流保证。

## 验证与部署

新增纯函数测试位于 `tests/studio-core.test.cjs`，纳入已有 `npm test`。原验证及 Cloudflare 构建流程保留，新目录和入口脚本加入静态产物清单。

新工作台是静态前端。新增后台函数已部署在仓库原有 Supabase 项目，核验其组织计划为 Free；没有新建收费项目、不改数据库、不替换旧聊天接口。`studio/api.js` 使用项目公开 anon key（不是服务密钥），后台开启 JWT 校验。免费计划仍有用量上限，不能保证永久可用。当前 Render 和 Cloudflare 前端发布仍由仓库原有流程执行，后台部署不等于前端已上线。
