# 单独添加新角色

打开“角色中心 → 上传角色代码”，可上传JSON/JS文件，也可在代码框里直接编写或粘贴，再点击“生成角色”。“使用模板”会填入一个有独立id的新角色配置，修改姓名、性格和其他字段即可；未提交的代码在关闭弹窗或刷新后，仍保留在同一个浏览器标签页中。电脑可用Ctrl/Cmd+Enter生成。

只需修改模板中的 `id`、`name` 和 `personality`；年龄、性别、头像、人设细节与快捷话题都能一起填写。上传 JSON 文件，也支持 `.js` 文件中的 `export default {…}`，其中对象仍须是双引号的标准 JSON。文件里的程序不会执行。

同一 `id` 重复导入会跳过，改一个 `id` 可以再创建一个角色。角色头像可先沿用模板人像，也可在创建角色时从相册选择。
